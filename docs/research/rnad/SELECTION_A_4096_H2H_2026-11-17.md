# I5: A4096 vs A2048 選出AIの権威完全4勝Match 実戦比較（事前登録）

## 目的
A4096は、未使用教師2048完全MatchでTop1 55.26%、3相Bonferroni相当の選出**単体**80%片側下限52.71%を記録した（Run #44067733118）。それでも教師Top1の改善は実戦勝率の改善を意味しない。前回A2048対A1024の権威Match実勝率50.78%・95%CI [48.05%, 53.52%]は優位差未確証だった（Run #44065730800）。A4096の有効性を独立評価する。

## 事前固定
- 新モデル: Run #44067733118のモデル台帳に事前選定した`selection-A-4096-e60-s90252.pt`。旧モデル: Run #44058355205の`selection-A-2048-e40-s90252.pt`。両者のSHAとsource/engine/public actor vocabularyを照合。
- `scripts/rnad/export_selection_a_js.py`でPyTorch→JSへの凍結モデル変換。Python側の全60合法選出候補 logits とJavaScriptの数値一致を検証し、教師targetや相手未公開の型・持ち物などを推論に使わない。
- 権威`runPhaseMatch`のドラフト両席`strategy`・戦闘両席`basic`は変えず、**選出のみ**凍結A2048とA4096に交換。
- 独立512 seed（**2500001～2500512**）につきA4096の座席0/1を交換し、計**1,024完全4勝Match**。これは教師学習用seed2494001～2495024・教師確認seed2496001～2498048と重複しない。
- 各seedの2試合で得た新A4096の勝利数を0, 1/2, 1の単位で平均。seed-cluster bootstrap10,000回の近似95%両側CIを報告。**下限>50%のみ**実戦優位の証拠とする。
- 比較可能な強度は`strategy`ドラフト・`basic`戦闘の固定条件のA4096 vs A2048だけで、AQ-Base等との優劣やChampion条件を主張しない。
- 実装・契約検証は`scripts/rnad/evaluate-a4096-vs-a2048-headtohead.mjs`と専用GitHub-hosted `.github/workflows/rnad-i5-selection-a-4096-headtohead.yml`で行い、workflow起動は`SELECTION_A_4096_H2H_LAUNCH_2026-11-17.json`の追加時だけ。既存H2H Run #44065730800を再実行しない。
- 今回のデータでモデル再選択・追加学習をしない。**同一3フェーズ統合policyゲート、Champion昇格、リーグ開始、PRのmain統合は保留**。独立ChatGPT Chatレビューは別セッションで必要。
